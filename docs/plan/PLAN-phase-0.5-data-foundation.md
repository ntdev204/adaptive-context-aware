# Phase 0.5: Data Foundation

> Dataset schema, record format, sample fixtures — extracted from Phase 7

---

## Goal

Establish the data contracts that all downstream phases depend on: annotation schema, sensor record format, bootstrap test fixtures, and model I/O contract tests. This unblocks Phase 1 (perception needs input/output specs) and Phase 2+ (needs annotation format for training).

## Prerequisite

Phase 0 (Infrastructure) complete — project scaffold, Docker, CI/CD exist.

## Spec Reference

All implementations MUST conform to `docs/specs/data-schema.md`.

---

## Tasks

- [ ] **T0.5.1**: Finalize annotation schema (from `data-schema.md` §3)
  - Create JSON Schema file: `config/schemas/annotation_schema.json`
  - Create enum definition file: `src/utils/enums.py` (Activity, SceneContext, IntentDirection)
  - → Verify: `pytest tests/unit/test_data_schema.py -k json_schema` — sample JSONs validate

- [ ] **T0.5.2**: Implement HDF5 record/replay (from `data-schema.md` §2)
  - Create `src/utils/hdf5_recorder.py` — write sensor data to HDF5
  - Create `src/utils/hdf5_reader.py` — read and iterate over recorded data
  - Match structure in `data-schema.md` §2 exactly
  - → Verify: `pytest tests/unit/test_hdf5_io.py` — record 60s synthetic → replay identical

- [ ] **T0.5.3**: Create bootstrap test fixtures
  - **Committed (tiny, <10MB total):**
    - `tests/fixtures/images/` — 5 small person images (resized 320×240, committed to git)
    - `tests/fixtures/annotations/` — 5 sample annotation JSONs (hand-written)
    - `tests/fixtures/anomaly_synthetic/` — 20 hand-crafted anomaly test cases (JSON, <100KB)
    - `tests/fixtures/rl_scenarios/` — 5 fixed routing scenarios with expected outputs (JSON)
    - `tests/fixtures/sample_recording.h5` — synthetic 5s recording (generated by script, ~2MB)
  - **Generated locally on demand (not committed, gitignored):**
    - `tests/fixtures/cctv_person_subset/` — small subset extracted from `data/fine_tuning/cctv_person`
    - `tests/fixtures/mot20_subset/` — small subset extracted from `data/fine_tuning/mot20`
  - **Scripts:**
    - `scripts/download_fixtures.py` — extract local CCTV/MOT20 subsets for bootstrap tests
    - `scripts/generate_synthetic_fixtures.py` — generate synthetic HDF5 + anomaly data
  - Add `tests/fixtures/cctv_person_subset/` and `tests/fixtures/mot20_subset/` to `.gitignore`
  - CI/local bootstrap step runs `scripts/download_fixtures.py` before fixture-sensitive tests
  - → Verify: `pytest tests/unit/test_fixtures.py` — committed fixtures exist, local subsets available after script

- [ ] **T0.5.4**: Model I/O contract tests (from `data-schema.md` §5)
  - Create `tests/unit/test_model_contracts.py`
  - For each model: verify input shape/dtype → output shape/dtype matches spec
  - Use dummy weights (random initialization) — functional shape test only
  - → Verify: `pytest tests/unit/test_model_contracts.py` — all models pass
